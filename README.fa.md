# شبکه‌های ارتباطی پیشرفته — جزوه‌های دوزبانه

[English](README.md)

یک دورهٔ کامل دربارهٔ شبکه‌های ارتباطی موبایل از نسل دوم تا نسل ششم که با LaTeX نوشته شده و **از هر سند یک نسخهٔ انگلیسی و یک نسخهٔ فارسی** دارد.
دو نسخه ساختار، معادله‌ها، شکل‌ها، برچسب‌ها و شماره‌گذاری یکسانی دارند.

۲۶ درس از سرفصل مخزن
[AdvancedCommNetworks2026](https://github.com/AidinShekari/AdvancedCommNetworks2026)
پیروی می‌کنند. همهٔ متن‌ها، شکل‌ها و تمرین‌های این مخزن نوشتهٔ اصلی‌اند.

## محتوا

| بخش | درس‌ها |
|-----|--------|
| اول — مبانی نسل دوم و سوم | ۰۱ تا ۰۴: GSM/GPRS/EDGE، سوئیچ مداری، هستهٔ نسل دوم و سوم، تحرک و تحویل |
| دوم — دسترسی و هستهٔ نسل چهارم | ۰۵ تا ۱۳: معماری LTE، E-UTRAN، زمان‌بندی، دسترسی تصادفی، EPC، Diameter، HSS، MME، S-GW و P-GW |
| سوم — معماری‌های نرم‌افزارمحور | ۱۵ تا ۱۸: SDN، NFV، استانداردسازی 3GPP، معماری خدمت‌محور |
| چهارم — سامانه و رویه‌های نسل پنجم | ۱۴ و ۱۹ تا ۲۲: مقدمهٔ نسل پنجم، هستهٔ نسل پنجم، رویه‌ها، برش‌بندی، کیفیت خدمات |
| پنجم — صفحه‌ها و چشم‌انداز | ۲۳ تا ۲۶: صفحهٔ کاربر، صفحهٔ کنترل، تکامل شبکه، فناوری‌های نسل ششم |

هر درس چهارده بخش یکسان دارد: اهداف یادگیری، پیش‌نیازها، مقدمه، مفاهیم بنیادی، جزئیات فنی، مدل‌های ریاضی، معماری، رویه‌های گام‌به‌گام، مثال‌های
حل‌شده، مقایسهٔ فناوری‌ها، نکات کلیدی، تمرین‌ها (سه سطح)، پاسخ‌ها و مطالعهٔ بیشتر همراه با منابع.

فایل‌های PDF آماده در پوشهٔ [`pdf/`](pdf) هستند: `lecture-NN-en.pdf`، `lecture-NN-fa.pdf`، `syllabus-en.pdf` و `syllabus-fa.pdf`.

## ساخت

نیازمندی‌ها: TeX Live نسخهٔ ۲۰۲۲ یا بعدتر با XeLaTeX، `xepersian`، `bidi`، `biblatex` و `biber`، TikZ/PGFPlots و `latexmk`؛ و Python 3.

</div>

```sh
make all                    # همهٔ درس‌ها در هر دو زبان + طرح درس
make english                # فقط نسخه‌های انگلیسی
make persian                # فقط نسخه‌های فارسی
make lecture LECTURE=07     # یک درس، هر دو زبان
make check                  # بررسی گزارش‌های ساخت
make validate               # بازمحاسبهٔ مقادیر مثال‌ها
make clean
```

## بررسی کیفیت

* `scripts/check_logs.py`: خطاها، ارجاع‌ها و استنادهای تعریف‌نشده، نویسه‌های گمشده، جعبه‌های سرریز و مشکلات راست‌به‌چپ را گزارش می‌کند.
* `scripts/lint_sources.py`: هم‌ارزی دو نسخه، ساختار چهارده‌بخشی، پوشش سرفصل و برچسب‌های فارسی شکل‌ها را بررسی می‌کند.
* `scripts/validate_examples.py`: اعداد مثال‌ها و پاسخ‌ها را دوباره محاسبه می‌کند.

گردش‌کار GitHub Actions در هر push کل ساخت و هر سه بررسی را اجرا و فایل‌های PDF را به‌عنوان خروجی بارگذاری می‌کند.

* مثال‌های کمّی بر فرض‌های بیان‌شده و اغلب نمونه‌ای استوارند؛ مقادیر آموزشی‌اند، نه اندازه‌گیری یک شبکهٔ مشخص.
