\begin{landscape}
\textbf{Credits:} 2 units (1 theory + 1 practical), 48 h in total ·
\textbf{Format:} 1 h lecture + 2 h lab per week \textbf{Audience:} MSc
and final-year BSc students · \textbf{Prerequisites:} statistical
methods in cognitive science; experimental methods in cognitive
psychology \textbf{Language / tools:} English · Python 3 (numpy, scipy,
pandas, matplotlib; PyMC + ArviZ from Week 13), run on students' own
laptops

\subsection{Design principles}

\begin{itemize}
\tightlist
\item
  \textbf{One modeling pipeline used all term.} Every lab follows the
  same steps: \emph{simulate \ensuremath{\rightarrow} fit \ensuremath{\rightarrow} evaluate \ensuremath{\rightarrow} recover \ensuremath{\rightarrow} interpret}.
\item
  \textbf{A few datasets come back again and again.} Forgetting curves
  and signal detection theory (SDT) run through Weeks 2--13, so new
  methods are compared on familiar data. Chapter 6 adds categorization
  (GCM), response times (drift-diffusion) and reinforcement learning.
\item
  \textbf{``Write it yourself, then use the library.''} Students write
  least squares, maximum likelihood, grid posteriors,
  Metropolis--Hastings, Gibbs and R-hat by hand before using
  \nolinkurl{scipy.optimize}, PyMC or ArviZ.
\item
  \textbf{Chapter weighting.} Ch1: 2 weeks · Ch2: 3 · Ch3: 2 · Ch4: 2 ·
  Ch5: 3 · Ch6: 2. One more week each goes to orientation, the midterm
  and project presentations.
\item
  \textbf{``Metropolis--Gibbs'' means two separate algorithms:}
  Metropolis--Hastings (Week 11) and Gibbs sampling (Week 12).
  MH-within-Gibbs is covered as an Advanced box.
\end{itemize}

\subsection{Final project (overview; the full brief and rubric come in
Stage 3)}

\begin{itemize}
\tightlist
\item
  \textbf{Teams of 1--2.} The scope grows with team size. Everyone fits
  at least two candidate models, runs one model comparison and one
  parameter-recovery analysis. \textbf{Pairs also} do a Bayesian/MCMC
  analysis (or a hierarchical model) and submit an individual
  contribution statement.
\item
  \textbf{Data:} simulated data, an open dataset, or the student's own
  experimental data.
\item
  \textbf{Milestones:} team formation (Wk 7) \ensuremath{\rightarrow} proposal (Wk 9) \ensuremath{\rightarrow}
  progress check (Wk 13) \ensuremath{\rightarrow} presentation (Wk 16) \ensuremath{\rightarrow} report + code (before
  the final exam).
\end{itemize}

\subsection{Computing on students' own laptops}

\begin{itemize}
\tightlist
\item
  The full environment, PyMC included, is installed in \textbf{Week 1},
  so Windows/macOS installation problems are solved long before Week 13.
\item
  Recommended route: \textbf{Miniforge (conda-forge)} with a course
  \nolinkurl{environment.yml}, plus a pip \nolinkurl{requirements.txt}
  as an alternative (both delivered in Stage 4).
\item
  \textbf{Fallback:} every notebook also runs on Google Colab.
\end{itemize}
